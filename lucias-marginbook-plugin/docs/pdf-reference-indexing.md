# PDF 导航与摘录索引

普通 `[[文件.pdf#page=18|跳到 P18]]` 链接继续跳转 PDF，但不自动创建侧栏摘录或页面标记。目录、逐页精读、课程梳理中的页码链接无需更换格式。

精读文档可以在文件开头的 YAML 属性区明确声明：

```yaml
---
marginbook-role: reading-guide
---
```

已有 YAML 属性区时，在其中增加这一行，不另建第二个属性区。该属性只排除此文档贡献的摘录索引，不删除正文、链接、Canvas、PDF 或批注设置，也不影响 PDF 跳转。属性必须在文件开头的真实 YAML 属性区内，正文中的示例不会生效。

默认保留以下真实摘录：带 `^ex-...` 标识；带 `selection=` / `rect=` 选区；旧 PDF Flow 的四值 `select=` / `square=`；LMB 受控生成区、手动摘录区、词语备注区；`lmb-excerpt` 卡片；旧版 `> ([[文件.pdf#page=18|引用]])` 包装。无 ID 的旧摘录不要求迁移。原有 PDF Flow 坐标不重新解释，保持旧版定位行为。

对于完全没有上述标识、且确实以普通 PDF 链接记录摘录的自建文档，可设置 `marginbook-role: excerpts`，明确让该文档沿用原来的宽松识别方式。含有混合内容时，建议只给真实摘录加稳定的 `^ex-...` 块标识。

更新插件后重新加载，启动时会自动重建索引；也可运行 “Lucia's MarginBook: 重建摘录索引”。误识别记录从缓存排除，原始文件保留。简洁摘录、页注和手写批注使用自己的存储路径，不受这项 Markdown 解析规则影响。
