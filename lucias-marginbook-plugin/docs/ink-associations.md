# 手写与摘录、侧栏、Canvas 的关联（0.36.0）

## 使用

1. 开启 PDF 手写，切换到选择／套索，从笔迹外侧圈选。选中后出现“关联摘录”和“新建手写”两个文字按钮。
2. “关联摘录”只列当前 PDF 的条目；保留原摘录文字和已经写好的备注。“新建手写”输入标题，创建一条侧栏手写备注，失败时保留输入并允许重试。
3. 侧栏显示笔迹预览。点预览定位 PDF 对应区域，点“编辑原笔迹”直接选择原始笔迹，可继续移动、缩放、擦除。组内拖动保留多笔选择。
4. 手写备注可以使用现有侧栏 Markdown 实时编辑和自动保存。定位或切换前先保存；失败保留编辑器与草稿，停止跳转。
5. 侧栏“将手写引用放入 Canvas”在此 PDF 的专属画布创建一张引用卡。使用现有存储规则，例如 `Lucia's Marginbook/课程/文档/文档.canvas`；重复点击复用原卡片。
6. Canvas 卡片的 PDF 链接或笔迹预览可回到原位置；“编辑原笔迹”进入原始笔迹的套索编辑。拖动预览超过阈值不会触发回跳，卡片仍可正常整理布局。

已有摘录的普通行点击继续定位原文；其手写预览可单独定位关联笔迹，支持原文与手写位于不同页。同一条目可以关联多组笔迹，各组预览按各自页码定位。

## 数据约定

- 原始笔迹：沿用独立的按 PDF 存储文件，包含点、压感、时间、颜色和宽度；关联不复制或替换笔迹。
- `settings.inkExcerptLinks[pdfPath][exId]`：稳定引用 ID、分组页码、笔迹 ID 和页面比例。新建手写备注沿用 `quickExcerpts`，其 Markdown 备注沿用现有自动保存机制。
- Canvas：原生 text 节点包含 PDF 链接和 `marginbook-ink` 代码块，载荷仅为 `{ "ref": "inkref-..." }`。插件将它渲染为动态 SVG 预览；预览不替代完整的原始压感数据。
- 局部擦除后的片段带原笔迹来源 ID。关联跟随剩余片段，移动后重新计算定位范围；撤销可以恢复笔迹及关联，无需重新绑定。
- PDF 重命名时迁移关联表键。Canvas 的稳定引用 ID 保持不变，不依赖旧文件名的代码块载荷。
- 全部擦除后保留手写备注和 Canvas 占位提示，避免删除用户补充。删除手写备注的侧栏记录也保留原笔迹和已有 Canvas 引用。
- Canvas 修改先读取活动内存数据，再对克隆添加新节点；不调整原节点的位置、宽高、边或用户元数据。并发添加串行执行，写入失败不改变原快照。

引用卡依赖对应的插件数据和原始笔迹数据。备份或跨库迁移时，需要一起保留这些数据；复制一张引用卡不等于复制完整原笔迹。

## 0.37.0：统一编号、持续定位与引用卡高度

- 每份 PDF 的手写关联使用固定 H 编号；旧关联只补充编号，不改引用 ID、摘录或笔迹。编号计数单独持久化，删除后不复用，PDF 改名时随关联迁移。
- 同一 H 编号显示在选择工具、侧栏、PDF 持续定位外框、关联的 Markdown 文本块和 Canvas 预览。切换另一条批注清除旧定位；移动／擦除原笔迹后重新计算外框，不再在 1.8 秒后消失。
- Canvas 引用卡提供“返回原笔迹”和“编辑原笔迹”。原生 Canvas 的未选中卡片带透明交互层；显式按钮仅在自身区域接管首次指针点击，移动或取消不导航，预览与卡片拖动保留宿主行为。定位前仍通过现有 Markdown 保存队列，失败保留草稿并阻止跳转。
- 仅对渲染出的手写引用卡测量自然高度，可增高或缩短，宽度改变后重测。只向最新的 Canvas 内存快照合并目标高度，保留位置、宽度、其他节点、边和文本；编辑中的卡片跳过自动测量。不触发树排版或相邻节点重排。
- 从手写模式启动 Markdown 文本块放置时，先关闭手写捕获层，避免它挡住新文本块的编辑点击。

验证：9 组 Node 测试、305 项浏览器检查通过。Windows 上的真实 Obsidian 1.14.4 已验证首次按钮回跳、原笔迹继续编辑、自动高度、应用重载后的关联／备注恢复、页内和侧栏 Markdown 自动保存。备份后对照检查：37 份无关 Canvas 完全一致，另一份既有手写引用卡仅高度更新；既有 PDF、Markdown、笔迹文件及备注和页内布局配置未改变。验证使用隔离副本，不在用户原始内容上新增测试笔迹。详见 `tests/evidence/ink-workspace-0.37.0.json`。物理平板、触控笔及进程完全退出再启动尚未验证；全应用重新加载已验证。


## 0.38.0：继续手写与保存队列修复

- 去掉重复的“返回原笔迹”按钮；点击预览仍可定位。将“编辑原笔迹”改为“继续手写”：定位后直接启用画笔，显示当前 H 编号与“完成续写”。新增线条自动加入当前关联，侧栏和 Canvas 预览一起更新。移动、缩放仍使用套索。
- “完成续写”后画出的线条保持独立。切换 PDF、关联或选择／文本工具结束续写；橡皮及自动回到画笔保持续写目标。
- 新笔迹在原侧车文件对象中保存 `inkGroupIds`，沿用原始可编辑矢量数据；不复制旧笔迹，不替换原摘录备注，不重排 Canvas。局部擦除片段、撤销和重做保留关联。
- 修复空保存任务缓存已完成 Promise 的旧问题：它会导致随后补画停留在内存。无改动保存不再占用保存队列，并验证随后新增笔迹确实写入侧车文件。

验证：9 组 Node 测试、316 项浏览器检查通过。真实 Obsidian 验证续写、Canvas 回跳、结束续写及应用重新加载；磁盘与重载后的 Canvas 均恢复三笔关联，第四笔独立。既有已保存的 PDF、Markdown、Canvas 和笔迹文件完全一致，原备注配置保留。详见 `tests/evidence/ink-continuation-0.38.0.json`。物理平板／触控笔未验证；旧版本中从未写入磁盘且已丢失的笔迹，不能仅凭截图精确恢复，现有文件与提供的截图已备份。


## 0.39.0：关联管理与侧栏布局

- 粗细滑条与“删除所选”移到第一排，默认无需展开更多工具。
- 侧栏手写预览新增“解除关联”，即使笔迹已擦空也能解绑；仅移除引用，保留原始矢量、摘录和 Markdown 备注。失败恢复原绑定。Canvas 原卡片及其位置保留，显示关联不可用；不会自动删除节点或连线。重新关联使用新的引用及 H 编号。
- 套索选择后，按住“拖到摘录”拖到任意侧栏卡片，目标卡片显示边框反馈，靠近侧栏边缘可自动滚动。也可点“关联摘录”后直接点卡片。关联期间显示全部页的目标，完成或取消恢复原页面筛选和搜索；保存编辑器失败时保留草稿和目标模式，不跳转。
- 拖动取消、切换工具或 PDF、窗口失焦及退出手写会清理关联目标模式。放下后的兼容点击不会造成二次定位。
- 退出手写会清空套索选择与全部实时绘制层，并取消排队的绘制帧，修复选择框残留；不改原笔迹。
- 侧栏标题的“侧栏：右／左”按钮切换放置方向，位置写入设置；收起、展开、宽度拖动及手写工具栏跟随方向。改变布局不会重建 Markdown 编辑器，保存失败保持原位置。

验证：9 组 Node 测试和 335 项浏览器检查通过，另用真实浏览器鼠标事件验证拖放关联后不误定位。原生 Obsidian 已成功加载并显示位置按钮；检测到人工切换窗口后停止接管，未宣称完成全部原生流程或物理触控笔验收。数据备份对照：66 份已有文件中，41 份 Canvas 及全部原 PDF、Markdown 和笔迹文件未改变；原备注、页内布局、手写关联设置保持一致。详见 `tests/evidence/ink-sidebar-controls-0.39.0.json`。


## 0.39.1：按钮与滑条对齐

侧栏位置和展开按钮改用同一组布局，统一图标、边框、悬停与按下样式；桌面高 30px，触控高 40px。收起侧栏时保留可点击的展开入口，手写工具栏为它留出空间。粗细滑条显式重置宿主的轨道、圆点尺寸与偏移，按轨道 4px、圆点 16px 的几何关系居中，避免主题样式叠加位移。

9 组 Node 测试和 335 项浏览器回归通过；桌面／触控、左右侧栏下按钮顶边与高度差均为 0，滑块与轨道的像素中心差为 0。真实浏览器鼠标验证收起后的重新展开。详见 `tests/evidence/controls-alignment-0.39.1.json`；本次未接管实际 Obsidian 窗口或验证物理触控笔。


## 0.39.2：重复按钮与侧栏横向溢出

刷新按钮时显式清空旧内容，再创建单个图标与单个位置标签；不再依赖宿主 `setIcon` 是否清理已有子节点。之前的测试替身使用 `textContent` 覆盖，掩盖了累积问题。新增 `?controls=1` 使用保留旧内容的图标替身，在旧版本首轮刷新即复现失败，再验证反复刷新、切换左右、展开与收起后的唯一性。

侧栏仅纵向滚动；卡片、正文和操作区限制在可用宽度内，长代码和表格文字换行，操作按钮可换行，宽度拖动柄也移到侧栏边界内部，避免自身撑出横向滚动区域。

验证：9 组 Node 测试、335 项既有浏览器检查、84 项专项检查通过。专项覆盖 24 轮重复刷新及 260／340／560 宽度、左右侧栏和移动端样式，长内容在展开状态下验证。渲染截图核对：侧栏滚动宽度与可视宽度同为 339px，按钮保留一个图标和一个标签。逐项记录在 `tests/sidebar-controls-browser-results.json`，证据在 `tests/evidence/sidebar-idempotence-0.39.2.json`。本次未自动操作实际 Obsidian 或物理平板。


## 0.40.0：文字块选择、双击编辑与工具栏层级

- 单击 PDF 文字块只选中并固定上方调整工具栏；双击正文进入段落实时编辑，键盘 Enter／F2 也可编辑。编辑器内单击段落继续切换源码，不增加第二份预览。
- 点击空白、其他区域或 Escape 取消选择时，清除叶面的选中记录、标识和旧块焦点。取消文字编辑也解除其选择。编辑中的空白退出及切换均先经过原保存队列；失败保留草稿与焦点，不打开其他编辑器。
- 单击另一文字块保存当前内容后只选中目标，双击才打开目标编辑器。交互请求令牌阻止较慢的读取／保存结束后再打开已取消的编辑器。
- 选中块的整个堆叠层级提升到普通备注之上，因此其工具栏能盖过其他文字块并接受点击；工具栏由选中状态控制，移开鼠标也保留，取消后隐藏。

验证：9 组 Node 测试、440 项浏览器检查通过，新增 21 项覆盖选择／取消、鼠标／触控／笔事件、双击编辑、失败草稿、延迟取消与真实 DOM 遮挡命中。另以真实浏览器鼠标执行单击、移出、重叠工具栏点击、双击编辑和空白保存退出，并核对渲染截图。旧串联测试已按双击进入编辑的新交互更新，保存顺序、输入法、页回收和失败保护断言继续保留。详见 `tests/evidence/text-selection-0.40.0.json`。本次没有自动操作实际 Obsidian 或物理平板，不能将合成触控／笔事件视为真机验收。
