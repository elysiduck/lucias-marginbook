# Canvas 高度（0.34.0）

自动与手动高度使用固定外框宽度的自然布局副本测量，结果不依赖原卡片的固定高度。原外框与正文的高度差可能包含空白，不能作为外框间距加回测量值。有效 DOM 测量也不再被截图或 Markdown 估算值覆盖。手动应用后仍检查实际滚动宿主，必要时补高，避免裁掉长文。

实际尺寸缓存带 `naturalHeightVersion: 3`。打开画布或重载插件后，旧摘录卡缓存（包括此前点击“高度”产生的锁）会在 DOM 就绪后实测一次；未就绪时保留原几何数据，不拿估算覆盖。当前版本中内容与宽度均未变化的卡片，移动时不会重新测量；内容或宽度变化后允许重新测量。仅估算的结果保留 `pendingActual`，不作为已完成的锁定高度。

测量前恢复用户保存的文字／图片视图。被隐藏的截图不参与高度，也不阻塞图片加载等待。修复不会离线改写用户画布；在打开画布后的正常保存流程中更新需要修正的尺寸。

验证：`npm run build`、`npm run verify`；浏览器入口 `tests/canvas-height-preview.html`，覆盖 731 高度卡片、连续调整、旧缓存重测、图片切换、长文缩短、窄卡和缩放。
