# PDF Markdown 文本块（0.33.0）

页内工具条统一高度，缩小字号输入框并移除冗余编辑按钮；点击文字即可进入编辑。选中侧栏卡片后，对应页内文字块显示持续边框及页码编号。

侧栏的编辑备注／添加备注直接在原卡片中打开段落实时编辑，不弹窗。已放置的页内文字块同步预览草稿。侧栏和 PDF 页内编辑停止输入 800 毫秒后自动保存，状态显示在工具条；点击另一条卡片会先保存当前内容，再直接编辑目标备注。保存失败时保留当前草稿和选中状态并提示，不会切走；恢复写入后可再次点击目标卡片重试。“完成”立即保存并结束编辑；“取消”仅放弃最后一次成功保存之后的改动，已经自动保存的内容仍会保留。后台刷新及切换 PDF 保留草稿；保存失败保留编辑器。侧栏编辑时，卡片的收起和删除按钮暂时禁用，避免丢失草稿。浏览器回归入口：`tests/text-block-preview.html?sidebar`。

1. 在 PDF 批注侧栏找到摘录，点击“将 Markdown 备注放到 PDF 页面”（已放置的条目显示“重新放置”）。没有备注时会先打开 Markdown 编辑器。
2. 点击 PDF 页面的空白位置放置；Esc 取消。每条备注在同一个 PDF 中保留一个页面位置，重新放置会移动它。
3. 点击文本块显示工具条；拖动 ⠿ 移动，拖动右侧边缘调整宽度。改宽度会自动换行，字号独立调整，并跟随 PDF 缩放。
4. 点击正文段落，直接在原位置修改 Markdown；仅当前段落显示源码，其他段落保持渲染，不再重复预览。点击另一段即切换，表格、列表、代码和公式以完整区块编辑。支持段落间回车、跨段粘贴与 Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 重做；保存后两处同步。Ctrl/Cmd+Enter 保存，Esc 或“取消”恢复原文。也可以从侧栏进入原位编辑；未放置的备注直接在侧栏编辑。字号以页面参考单位保存，并非屏幕像素。
5. “侧栏收起”将条目压缩为一行页码、编号、批注标题或开头文字和“展开”按钮，超长文字显示省略号。没有备注时取摘录开头。点击展开恢复内容和操作；页面上的文本不受影响。旧版已隐藏的条目也自动以这种小入口出现。
6. “移除”只取消页面摆放，保留备注。长文超过页面剩余空间时在文本块内滚动。侧栏长备注默认收起，可展开。
7. 卡片右上角放置“收起为侧栏入口”和“删除摘录”。点击卡片正文即可定位 PDF。长备注的展开／收起控件嵌在备注右下角。
8. 按钮带边框、悬停高亮和按下反馈。卡片折叠在原位置更新；完整内容刷新也会先完成渲染、页码筛选和搜索过滤，再替换侧栏内容，保留页码统计及滚动位置。
9. 文本块的 A− / A+ 可逐级调整字号（8–72），也可继续输入数值。正文、表头、单元格使用同一字号，随 PDF 缩放。
10. PDF 顶部“新建 Markdown 页注”不需要先选中文字：点击按钮，再点页面空白处，直接在页内输入、预览并保存。新页注同时出现在该页和侧栏，头部标注“页注”。Esc 取消放置；取消编辑或保存空白内容不会创建记录。它可以独立编辑、收起、重新放置或删除。

内容继续保存在原摘录 Markdown 或简洁摘录备注中；位置、宽度、字号、样式和侧栏可见性保存在插件设置 `pdfTextBlocks`。本版是阅读器内的可编辑覆盖层，不会写入原始 PDF，也不包含 PDF 导出。

自动检查：`npm run build`、`npm run verify`。浏览器烟雾测试可从插件目录运行本地 HTTP 服务后打开 `tests/text-block-preview.html`；它复用实际控件和样式，但用替身实现 Obsidian API 和 Markdown 渲染，真实 PDF.js、Obsidian 主题、公式及移动设备仍需宿主实测。

0.29.1：PDF 原文摘录仅从 textLayer 发起，跨入页内批注的选区会被裁剪。取文、链接位置、矩形和附图使用同一个裁剪后范围；工具条不参与文字选择。已有污染摘录不会被自动改写，可重新选择原文创建正确摘录。浏览器原生 Range 回归：tests/pdf-selection-preview.html。

编辑段落按实际换行数增长或缩小，单行文字不再保留 textarea 默认的第二行空白。页内点击空白处会先保存再退出；点击另一条页内备注或侧栏卡片会先保存再切换，保存失败保留当前草稿。页内新建备注多次自动保存仍是同一条，不重复创建。右上角的侧栏状态按钮在收起后继续保留，可直接重新打开，并保留编辑状态。

0.34.1：新建页注在页面上的完整点击结束时创建编辑器，该次放置点击不会再次触发空白退出。空编辑器保持可输入；后续独立点击空白处才保存退出。等待旧备注保存期间的重复点击不会创建多份，Esc 可取消待完成的放置。
