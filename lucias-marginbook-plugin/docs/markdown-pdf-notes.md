# PDF Markdown 文本块（0.26.2）

1. 在 PDF 批注侧栏找到摘录，点击“将 Markdown 备注放到 PDF 页面”（已放置的条目显示“重新放置”）。没有备注时会先打开 Markdown 编辑器。
2. 点击 PDF 页面的空白位置放置；Esc 取消。每条备注在同一个 PDF 中保留一个页面位置，重新放置会移动它。
3. 点击文本块显示工具条；拖动 ⠿ 移动，拖动右侧边缘调整宽度。改宽度会自动换行，字号独立调整，并跟随 PDF 缩放。
4. 双击正文或点击“编辑”修改 Markdown，也可以在侧栏编辑。内容只有一份，保存后两处同步。字号以页面参考单位保存，并非屏幕像素。
5. “侧栏收起”将条目压缩为一行页码、编号、批注标题或开头文字和“展开”按钮，超长文字显示省略号。没有备注时取摘录开头。点击展开恢复内容和操作；页面上的文本不受影响。旧版已隐藏的条目也自动以这种小入口出现。
6. “移除”只取消页面摆放，保留备注。长文超过页面剩余空间时在文本块内滚动。侧栏长备注默认收起，可展开。
7. 卡片右上角放置“收起为侧栏入口”和“删除摘录”。点击卡片正文即可定位 PDF。长备注的展开／收起控件嵌在备注右下角。

内容继续保存在原摘录 Markdown 或简洁摘录备注中；位置、宽度、字号、样式和侧栏可见性保存在插件设置 `pdfTextBlocks`。本版是阅读器内的可编辑覆盖层，不会写入原始 PDF，也不包含 PDF 导出。

自动检查：`npm run build`、`npm run verify`。浏览器烟雾测试可从插件目录运行本地 HTTP 服务后打开 `tests/text-block-preview.html`；它复用实际控件和样式，但用替身实现 Obsidian API 和 Markdown 渲染，真实 PDF.js、Obsidian 主题、公式及移动设备仍需宿主实测。
