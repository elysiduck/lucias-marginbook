# AI 词汇卡（0.47.0）

在设置 → Lucia's MarginBook → AI 词汇卡填写 API 接口地址、API Key 和模型名称，再点击“测试连接”。接口须兼容非流式 Chat Completions，返回 `choices[0].message.content`；支持基础地址和完整 `/chat/completions` 地址。本地免密接口的 Key 可以留空。百炼例：`https://dashscope.aliyuncs.com/compatible-mode/v1`，模型 `qwen-flash`。百炼请求关闭思考模式；其他服务采用兼容接口默认行为。暂不支持原生 Anthropic Messages、Gemini generateContent 或 Responses 格式。

在 PDF 选中单词或短语，点击浮动工具条的语言图标（Aa 查词建卡）。最多 160 字符、12 个词；图片选区不显示入口。新卡片立即写入摘录文档独立的 `LMB:WORD-NOTES` 区域，不创建截图或 Canvas 卡片。元数据保留词语和从当前 textLayer 选区附近提取的少量语境；提取失败时只查词。结果作为现有 Markdown 备注保存，可以沿用侧栏和页内编辑、收起及定位。

侧栏以 Aa 词汇标题和专属边线区分；收起后保留词语标题。类型筛选与当前页／全部页及搜索组合使用。生成内容包括中文释义、词性／音标（允许空）、原句及翻译、一个双语生成例句，并标记为 AI 内容，不伪造词典来源。

同一处选区重复点击只打开已有卡片，其他位置的同词保留独立语境。侧栏语言按钮支持重试；已有备注重新查询时先打开结果预览，用户保存后才替换。等待期间发生编辑、删除、卸载时，结果不能覆盖原备注或重新创建被删除的卡片。超时为 45 秒；宿主底层请求无法中止，但超时后的返回不会写入。重启后保留原词和待查询提示，可手动重试。

只在主动查词或测试连接时联网，没有启动批量查询和自动后台重试。关闭“发送原句语境”后请求只包含所选词语；PDF 原文不会整本上传。API Key 保存在本地插件 `data.json`，未加密，同步此配置文件也会同步 Key；不会写入词汇卡。调用按服务商计费；连接测试也会发送一次小型查词请求。

自动检查覆盖实际请求参数、设置保存加载、Markdown 元数据重建、选区去重、失败重试、错误响应、手动修改冲突、删除与卸载保护、侧栏类型样式及组合筛选。测试使用模拟网络；实际服务、Obsidian Markdown 渲染及实体 iPad 仍需配置后确认。
